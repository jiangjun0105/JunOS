# September 2026

**Building.** Still refining the agent harness. This month's target is to have it build a SQLite implementation with zero or near-zero intervention from me, so I can compare the result against Cursor's much-discussed SQLite project.

**Researching.** Closing the loop between one leg and the brain in the digital fly. If the loop holds, the next thing to look for is whether proactive stimulation produces measurable changes in the network's weights, and whether those changes help. The accurate, many-jointed leg model only covers one leg — the other five are simplified, with far fewer joints — so after that the job is building proper multi-joint motor models for them.

**Reading.** Next up is Phantoms in the Brain — Ramachandran again, the book before The Tell-Tale Brain.
