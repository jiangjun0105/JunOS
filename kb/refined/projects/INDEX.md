**[Agent Harness](agent-harness.md)** — Multi-agent SDLC automation built bottom-up: project → epics → issues → tasks, each served by coder, reviewer, and tester agents with human review gates. Nothing was automated until it had been run by hand and proven. 10x+ single-developer velocity; Digital Double, a voice-AI education project, now runs through it. Next: whole projects, starting with Cursor's SQLite benchmark.

**[JunOS](junos-website.md)** — This site: a 3D wireframe San Francisco as the desktop. The first thing I designed with AI (describe → quick HTML options → feedback → narrow), and my view that AI shifts humans toward supplying will and taste.

**[Large-repo understanding tool](repo-understanding-tool.md)** — An AST-shaped hierarchical graph of agents that answered questions over large Python codebases better than Copilot Chat, built when GPT-3.5 was the frontier. Deliberately stopped when GPT-4 and growing context windows made it clear I was walking into the Bitter Lesson.
